Start with the manuals

Two books: one for the people who install and run the service, one for the people who build and run jobs in it. Jump straight to any part.

Administrator Manual

Deployment, first-run bootstrap, access and agencies, secrets, GitOps sync, the runner fleet and day-2 operations.

  1. IAdministering CronomiconWhat the service is made of, the first sign-in, and who may do what
  2. IIOperationsExecution, Git sync, secrets, the runner fleet and deployment
  3. IIIReferenceTroubleshooting, glossary and appendices

User Manual

Every screen, the ideas behind them, and task recipes for operators and job authors.

  1. IOrientationCore concepts, your first job, roles and permissions
  2. IIView ReferenceEvery screen, each control, and who may use it
  3. IIITask RecipesEnd-to-end walkthroughs of common tasks
  4. IVReferenceTroubleshooting, glossary and appendices

Runner guides

Runner agents execute jobs inside networks the server cannot reach. These guides take a runner from install to retirement.

  • InstallChoosing slim or fat, the one-line installer, TLS trust, systemd and container installs.
  • ManageStatus and health, upgrades, resync, managed settings, tags and retiring a runner.
  • SecurityWhat crosses the wire, key custody, host-key trust, hardening and residual risks.

Writing jobs

How a script receives its targets, inputs and secrets, and how it reports back, in each language Cronomicon runs.

  • BashShell scripts over SSH or on a runner.
  • AnsiblePlaybooks, inventories and project checkouts.
  • PowerShellWindows fleets, auth, inputs, outputs and secrets.
  • PythonTargets, inputs, outputs, exit codes and secrets.

Training courses

Self-paced courses that open as slides, one idea at a time, with checks along the way. Each can also be read as one page.

  • Operator courseTen modules for people who run and watch jobs.
  • Administrator courseSeven modules for the people who run Cronomicon.

Read them offline.

Every GitHub Release attaches these pages as cronomicon-docs-X.Y.Z.zip. Unzip it and open administrator-manual.html. A checkout of the repository has them too, in backend/web/dist/, and they open in a browser straight from disk.
